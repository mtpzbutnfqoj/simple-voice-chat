## Overview

Simple Voice Chat adds a fully functional proximity-based voice chat system to Minecraft that works across Fabric, Forge, Quilt, and NeoForge mod loaders. Players within configurable range hear each other naturally in 3D positional audio, with support for group channels, audio input device selection, push-to-talk and open-mic modes, and a built-in server-side plugin API for custom voice zones.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Simple Voice Chat** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Proximity Audio** | 3D positional voice audio — louder when players are closer together |
| **Multi-Loader** | Works on Fabric, Forge, Quilt, and NeoForge with a single download |
| **Group Channels** | Private voice group channels for party communication across distances |
| **Server Plugin API** | Bukkit/Spigot plugin API for custom voice zones and access control |
